# PRD-006 pull request description

## Title

Add structured scientific annotation editor

## Summary

This PR adds strict western-blot annotation contracts, immutable structured snapshots, prediction
acceptance and semantic diffs, canonical entity lookup, and a typed reviewer editor with optimistic
autosave and revision-based undo. It implements PRD-006 only.

## Architecture changes

- Adds typed contracts for protein targets/loading controls, cell lines, tissues, organisms,
  genotypes, treatments/doses/durations, lanes, antibodies, molecular weights, replicates, canonical
  references, and validated scientific relationships.
- Extends immutable `AnnotationRevision` with an optional structured western-blot snapshot.
- Adds migration `0006_structured_annotations` for the JSONB persistence representation.
- Adds `StructuredAnnotationService` for prediction parsing, individual/bulk acceptance, semantic
  comparison, canonical lookup, optimistic saves, and append-only undo.
- Adds strict editor, acceptance, save, undo, and lookup APIs under `/api/v1`.
- Adds `/annotate/{case_id}` and links it from the queue and source workbench.

## Migration table

| Previous behavior | PRD-006 behavior | Reason |
|---|---|---|
| Generic scalar field annotations only | Optional typed western-blot snapshot on each revision | Complex scientific records and relationships need one validated graph. |
| Reviewer manually rewrites model fields | Individual or bulk prediction acceptance | Unchanged predictions should be reviewable without transcription. |
| Raw revision snapshots only | Semantic prediction-versus-review diffs | Reviewers need scientific changes rather than opaque JSON changes. |
| No canonical lookup | Bounded vocabulary-aware suggestions | Canonicalization must preserve original extracted text. |
| No editor-level undo | Restore appends a new revision | History must remain immutable and auditable. |

Existing rows require no backfill; `structured_annotation_json` is nullable. The down migration
drops only the new check/column and its migration record.

## Preserved behavior

- Raw and normalized predictions remain independent immutable records.
- Historic annotation revisions remain queryable and unchanged.
- Existing generic field, spatial, relationship, rationale, and error-code snapshots still round
  trip; a structured autosave carries the current generic/spatial snapshot forward.
- PRD-005 source viewing and overlays remain read-only and use signed object-store URLs.
- Unknown fields continue to fail at strict Pydantic boundaries.

## Manual verification

1. Open a case at `/annotate/<case-id>` and verify all typed entity sections render.
2. Select a compatible prediction; accept one entity, then use **Accept all as predicted**.
3. Edit a target, loading control, context, dose, duration, lane, antibody, weight, and replicate;
   verify settled edits create increasing revision numbers.
4. Set an explicit ambiguous/unknown/absent/not-applicable state, reviewer note, and error code.
5. Resolve a protein or biological context through canonical lookup and verify original text remains.
6. Add lane/condition and target/loading-control relationships; verify incompatible graphs fail.
7. Open the same review in two windows and verify a stale save returns `409` without overwriting.
8. Restore an older revision and verify the restore itself appears as a new revision.
9. Add an unknown field in the advanced JSON editor and verify it is rejected without publication.

## Known limitations and deferred work

- The built-in canonical catalog is intentionally small and read-only; production ontology sources
  and organization terminology arrive in later PRDs.
- Only predictions already normalized to the new strict contract can be accepted. Legacy extraction
  migration begins in PRD-011.
- The local reviewer UUID is not authentication; backend RBAC and tenant isolation begin in PRD-017.
- Invalid drafts live only in the current browser until corrected; only valid settled states become
  immutable revisions.
- Geometry is displayed but not edited here. Spatial editing begins in PRD-007.
- This contract intentionally supports western blots only.
