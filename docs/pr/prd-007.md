# PRD-007 pull request description

## Title

Add bounding-region and relationship editor

## Summary

This PR adds strict source-pixel spatial graph contracts, immutable geometry saves and restore,
prediction acceptance and semantic diffs, and an interactive western-blot region editor. It
implements PRD-007 only and reuses the artifact, evaluation, workbench, and structured-review
foundations from PRD-002 through PRD-006.

## Architecture changes

- Adds `SpatialAnnotationSet`, typed spatial relationships, and semantic geometry comparison
  contracts with committed JSON Schemas.
- Validates bounds, source coordinate consistency, containment hierarchy and enclosure, graph
  endpoints, semantic edge uniqueness, lane forks/order cycles, and relationship compatibility.
- Adds `SpatialAnnotationService` for reviewer projections, individual/bulk prediction acceptance,
  optimistic immutable saves, surface-scoped restore, and stable-ID geometry diffs.
- Preserves current field/structured snapshots and generic relationships during spatial changes;
  relationship-ID collisions fail explicitly.
- Adds strict spatial editor, save, acceptance, and restore APIs under `/api/v1`.
- Adds `/spatial/{case_id}` with source switching, prediction/reviewer overlays, source-pixel create,
  move, resize, delete, split, group, lane reorder, relationship editing, keyboard controls,
  autosave, history, zoom, pan, rotation, and fullscreen.
- Links geometry editing from the review queue, source workbench, and structured editor.

## Migration table

| Previous behavior | PRD-007 behavior | Reason |
|---|---|---|
| Read-only source overlays | Editable reviewer geometry on image/page-render artifacts | Golden data requires direct correction of spatial predictions. |
| Generic relationship strings | Strict spatial relationship vocabulary and graph validation | Invalid hierarchy and lane-order graphs must not be publishable. |
| Geometry compared as opaque revision data | Added/removed/modified/unchanged regions keyed by UUID | Array order is not a scientific difference. |
| Whole-review restore risk | Spatial restore carries forward current non-spatial review data | Geometry work must not revert structured corrections. |
| Browser-scaled rectangles | Immutable source-pixel coordinates in the canonical contract | Geometry must survive viewport and zoom changes reproducibly. |

No database migration is required. Existing `spatial_annotations` and `annotation_relationships`
tables already store the canonical fields. Spatial verbs receive a `spatial:` persistence namespace
and are classified with endpoint membership, so same-named historic generic edges are retained.

## Preserved behavior

- Predictions and reviewer revisions remain separate, immutable, and independently queryable.
- Structured western-blot annotations, generic field annotations, rationale, error codes, and
  unrelated relationships survive spatial autosaves.
- Source metadata and large bytes retain the PRD-005 boundary: metadata through FastAPI, active
  source bytes directly through an expiring object-store URL.
- Existing review queue, workbench, and structured editor routes continue to work and now link to
  geometry editing.
- Unknown request fields and coercible-only canonical values remain rejected.

## Manual verification

1. Open a case at `/spatial/<case-id>` and confirm its active image streams from a signed object URL.
2. Toggle prediction and reviewer overlays; select and accept one predicted region, then accept all.
3. Create every supported region type, drag and resize regions, edit exact numeric coordinates, and
   verify out-of-bounds geometry is rejected without publication.
4. Split one region, group two regions, link a label, define containment, and link a target row to a
   loading-control row.
5. Reorder lanes with buttons and `[`/`]`; reload and verify the order survives as `precedes` edges.
6. Resize the browser, zoom, pan, rotate, switch sources, and verify source coordinates and each
   source's viewport remain stable.
7. Wait for autosave and verify a new revision, semantic geometry diff, rationale, and error code.
8. Open the same review in two windows and verify a stale save returns `409` without overwriting.
9. Restore an older geometry revision and verify the restore is a new revision while current
   structured annotation data remains unchanged.

## Known limitations and deferred work

- Native PDFs are read-only; spatial edits require an image or page-render artifact.
- Prediction regions must already exist as explicit `PredictionEvidence.region` values. Automatic
  western-blot detection is migrated in PRD-011.
- Region labels identify target/loading-control rows for review, but full scientific entity linkage
  remains in the structured annotation graph.
- The local reviewer UUID is not authentication; backend RBAC and organization isolation begin in
  PRD-017.
- This PR does not calculate pixel intensities. Deterministic densitometry begins in PRD-012.
- Large tiled-image pyramids are deferred; ordinary images use progressive browser decoding and
  direct signed URLs.
